Module 2: Frequency Response

Study how a first-order system changes the amplitude and phase of a sinusoidal input at different frequencies.

Magnitude: M(ω) = 1 / √(1 + (ωτ)²)  (output amplitude = K·A·M)
Phase: φ(ω) = −tan−1(ωτ)
Cutoff frequency: ωc = 1/τ rad/s

Module 3: Second-Order Systems

Compare underdamped, critically damped, and overdamped systems.

Transfer function: G(s) = Kωn² / (s² + 2ζωns + ωn²)

System Parameters

ζ < 1: underdamped; ζ = 1: critically damped; ζ > 1: overdamped.
